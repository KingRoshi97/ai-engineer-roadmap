# AI Development Environment Checker

A Python-based environment validation tool created during Phase 0 of my AI Engineer Career Roadmap.

## Purpose

This project verifies that the core software and system requirements needed for AI engineering development are installed and available.

## What It Checks

The checker validates:

- Python installation
- Active Python virtual environment
- Git installation
- Requests package
- Operating system
- System architecture
- Docker installation
- PostgreSQL client installation
- Available disk space
- Internet connectivity

## Requirements

- Python 3
- Git
- Docker
- PostgreSQL
- Requests
- Pytest
